# 视觉读取 SOP

用于 Word 简历预处理、图片、扫描件、复杂排版 PDF、设计师作品集、长作品集，或文本提取明显缺失/乱码/错位的简历。

## 1. 预检分流

先判断：

- 文件类型：Word / 文本简历 / 扫描简历 / 图片 / 普通 PDF / 作品集 / 混合文件。
- 页数。
- 是否有可复制文本。
- 是否存在复杂排版、截图、图表、设计稿、低清晰度页面。

能稳定文本提取的内容先用文本读取；视觉模型用于补全文本读取不到或不可靠的页面。

## 2. Word 简历预处理

HR 上传 `.doc` 或 `.docx` 时，先运行预处理脚本，不要直接从 Word 原文件读取后评分：

```bash
python scripts/prepare_resume_file.py --file "<HR上传文件路径>"
```

处理规则：

- 脚本返回 `converted: true` 时，后续全部使用 `reading_file` 指向的 PDF。
- pending JSON 中 `简历文件路径` 写转换后的 PDF 路径，`原始简历文件路径` 写 HR 上传的 Word 原路径。
- `阅读范围` 需要写明“Word 已转换 PDF 后读取”，例如：“Word 已转换为 PDF，共 2 页，完整读取全文。”
- 转换失败时，不要继续评分；请 HR 重新上传 PDF，或让 HR 先在 Word/WPS 中手动导出 PDF。

## 3. 页级目录

视觉读取先产出页级目录，不直接评分。内部记录：

- 页面或页面范围。
- 页面类型：简历首页、教育/经历、项目封面、项目过程、设计稿、数据结果、证书、无关页等。
- JD 相关度：高 / 中 / 低。
- 阅读动作：跳过 / 速览 / 深读 / 需要复核。
- 清晰度问题：模糊、遮挡、截图过小、图表文字无法识别等。

## 4. JD-aware 深读

读完 JD 后，先提炼本次扫描锚点，再按锚点找证据。常见锚点：

- 岗位硬要求。
- 作品集是否存在。
- AI / Agent / AIGC 经验。
- B端、增长、设计系统、产品设计、工程落地经验。
- 业务目标、用户问题、方案迭代、数据结果。
- 跨团队协作、客户沟通、文档沉淀。

不要被视觉风格、品牌背书或漂亮排版单独带偏。

## 5. 长作品集规则

- `<=15页`：完整阅读，每个项目给出证据页。
- `16-50页`：先全局速览并生成页级目录，再按 JD 相关性深读最多 20 页；每个主要项目至少看封面、目标、过程、结果页。
- `>50页`：先速览目录、项目结构和项目起止页，再按 JD 相关性深读最多 25 页；除非 HR 明确要求，不全量精读。必须说明哪些项目只速览、哪些项目深读。

## 6. 证据化笔记

关键通过/淘汰/风险判断尽量附页码或页面范围。没有页码来源的结论只能作为弱信号。

必须二次核对：

- 日期。
- 学历、毕业时间、在校状态。
- 工作年限。
- 作品集是否存在。
- GitHub / 作品链接是否出现。
- JD 硬性要求。

不确定就写不确定，不要猜。

## 7. 内部笔记格式

可写入 pending JSON 的 `视觉阅读笔记` 字段；对 HR 只展示自然语言摘要。

```json
{
  "file_type": "resume | portfolio | scan | mixed",
  "page_count": 82,
  "page_map": [
    {"page": 1, "type": "简历信息", "jd_relevance": "high", "read_action": "deep", "note": "候选人基本信息和经历概览"},
    {"page": "8-21", "type": "AI项目", "jd_relevance": "high", "read_action": "deep", "note": "与JD核心要求相关"}
  ],
  "evidence": [
    {"claim": "有AI产品0到1经验", "pages": "8-12", "evidence": "页面展示需求、方案迭代和上线结果"}
  ],
  "uncertainties": [
    {"field": "毕业时间", "pages": 1, "reason": "页面未明确写出"}
  ],
  "coverage": "速览82页；深读1-4、8-21、35-48页"
}
```

## 8. 失败处理

- 关键页模糊：单独复读该页或请 HR 补图/补文字。
- Word 转 PDF 失败、文件损坏或无法识别：请 HR 换 PDF 文件，或先手动导出 PDF。
- 信息缺失但可继续判断：写入不确定项，不阻断评分。
